# 🚀 Zoro Delivery App - Website

![Zoro Logo](zoroAppLogo.png)

Welcome to the official website of **Zoro Delivery**, the lightning-fast delivery platform for food, groceries, and essentials. This repository contains the source code for the Zoro landing page, designed to provide a premium and seamless experience for customers, businesses, and riders.

## 🌐 Live Demo
Visit the live site at: [zorodelivery.com](https://zorodelivery.com/)

## ✨ Key Features

### 🛒 For Customers
- **Instant Deliveries**: Record-breaking delivery times for all your orders.
- **Pay on Delivery**: Support for Cash and UPI payments at your doorstep.
- **Exclusive Offers**: Daily discounts, free products, and free deliveries.
- **Zero Hidden Charges**: Transparent pricing with no surprise fees.

### 🏢 For Businesses
- **Free Digital Store**: Launch your shop in minutes with zero setup costs.
- **Unlimited Inventory**: Add as many products as you want with custom offers.
- **Scale Your Reach**: Showcase your products to thousands of local customers.
- **24h Settlements**: Fast payments directly to your bank account.

### 🏍️ For Riders
- **Zero Commission**: Keep 100% of your earnings. No hidden deductions.
- **Be Your Own Boss**: Complete flexibility to work whenever you want.
- **Transparent Income**: Clear tracking of your earnings and performance.

## 🛠️ Technology Stack

This project is built using modern web technologies to ensure performance, responsiveness, and aesthetic excellence.

- **HTML5**: Semantic structure for better SEO and accessibility.
- **Vanilla CSS3**: Custom design system with:
  - **Glassmorphism**: Elegant blur effects and transparency.
  - **Dynamic Animations**: Smooth transitions and hover effects.
  - **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **Font Awesome**: Premium iconography.
- **Google Fonts**: Modern typography using *Outfit* and *Plus Jakarta Sans*.

## 🚀 Getting Started

To run this project locally, simply clone the repository and open `index.html` in your browser.

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge).

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/zoro-website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd zoro-website
   ```
3. Open `index.html` in your browser.
